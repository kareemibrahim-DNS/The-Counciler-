# Reseller reply procedure

Use this skill for every in-scope reseller question.

1. Classify the ask into one or more of: partners, line items, quote structure, price, country coverage.
2. If the ask needs a country (partners filter or any price) and the user did not give one, ask for the country before calling price tools.
3. Call the matching tool(s). Prefer ids from prior tool results in the turn.
4. Answer only from tool results.
5. For quote structure, always include both Commercial and Operational blocks and name the partner.
6. For prices, state country + currency + amount + unit. Mention that other countries differ.
7. If off-topic, refuse in one sentence — do not use tools.
